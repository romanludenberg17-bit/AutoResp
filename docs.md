# AutoResp — техническая документация

## архитектура

AutoResp — single-file Python plugin. Основная логика находится в `AiResp.plugin`.

Плагин использует:

- `BasePlugin` и update hooks exteraGram
- `ui.settings` для настроек
- `client_utils.run_on_queue` для сетевых операций вне UI-потока
- `client_utils.send_text(..., account=account)` для ответа от правильного Telegram-аккаунта
- встроенный `requests`, который уже доступен в окружении exteraGram

## обработка сообщения

1. exteraGram передаёт `TL_updateNewMessage` или связанное обновление.
2. AutoResp проверяет `enabled`.
3. отбрасывает исходящие сообщения и пустой текст.
4. определяет `dialog_id`.
5. проверяет фильтры личных сообщений/групп.
6. проверяет расписание.
7. добавляет сообщение в локальный контекст диалога.
8. ставит задачу в `EXTERNAL_NETWORK_QUEUE` с заданной задержкой.
9. получает список моделей Gemini, если выбран `auto`.
10. отправляет `generateContent` с системным промптом и контекстом.
11. отправляет результат в тот же аккаунт Telegram.

## авто-выбор модели

При `model=auto` плагин запрашивает `/v1beta/models`, оставляет модели с `generateContent` и отдаёт приоритет эффективным текстовым моделям Flash/Flash-Lite. Список кэшируется на 30 минут.

Это сделано специально, чтобы не зашивать устаревшее имя модели в код: Google может добавлять, заменять и выводить модели из эксплуатации.

## контекст

Контекст хранится только в памяти процесса плагина и ограничивается последними 30 сообщениями на диалог. В API отправляется количество, указанное пользователем в `context_count`.

После перезапуска exteraGram этот временный контекст очищается.

## безопасность

Gemini API key не находится в исходнике. Значение хранится через штатное хранилище настроек `BasePlugin`.

Плагин не содержит собственного backend-сервера и не пересылает сообщения на сторонний сервер автора. Сетевой запрос из плагина идёт непосредственно к Google Gemini API.

## ограничения

- для корректной работы с несколькими аккаунтами требуется SDK `>=1.4.5.0`;
- нужен exteraGram `12.5.1+`;
- для Gemini нужен действующий API key;
- бесплатные квоты Gemini зависят от текущих ограничений Google;
- ответы возможны только для новых сообщений, которые плагин реально получает после включения;
- если Gemini вернул ошибку или пустой ответ, сообщение не отправляется.

## формат расписания

Дата:

```text
YYYY-MM-DD
```

Время:

```text
HH:MM
```

Поддерживаются и обычные интервалы, и интервалы через полночь, например `22:00` → `06:00`.
