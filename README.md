# AutoResp

AI-автоответчик для exteraGram на Python с прямым Gemini API.

## что уже есть

- готовый исходник `AiResp.plugin`
- Material-style страница настроек через штатный UI exteraGram
- Gemini API без собственного сервера
- автоматический выбор доступной модели
- ручной выбор модели
- режимы качества: экономный / рекомендуемый / усиленный
- собственный системный промпт
- случайная задержка перед ответом
- контекст последних сообщений в активном диалоге
- режим только личных сообщений
- опциональная работа в группах
- расписание: всегда или заданное окно даты/времени
- кнопка помощи `?`
- встроенная проверка Gemini API
- безопасная привязка отправки к аккаунту, который получил сообщение

## установка

`AiResp.plugin` — канонический исходник плагина. В экосистеме exteraGram `.plugin` используется как исходный файл плагина; отдельной сборки проекта для этой версии не требуется.

для актуального SDK нужен exteraGram с поддержкой SDK `>=1.4.5.0` и приложение не ниже `12.5.1`.

в exteraGram должны быть включены `Preferences → Plugins` и developer mode, если установка выполняется как локальный пользовательский плагин.

## настройка

1. установи/импортируй `AiResp.plugin`.
2. открой настройки AutoResp.
3. вставь свой Gemini API key.
4. нажми `Проверить Gemini API`.
5. оставь модель `auto` или укажи конкретную.
6. задай промпт и задержку.
7. включи автоответчик.

ключ API не прописан в репозитории и не отправляется в GitHub. Запросы к Gemini выполняются непосредственно с устройства.

## Gemini

AutoResp использует REST endpoint `generateContent` и endpoint списка моделей. Google документирует оба API; доступные модели и квоты зависят от текущего проекта и тарифного уровня API.

## важно

бесплатный Gemini tier не означает безлимитное использование: Google может применять ограничения запросов/токенов и менять доступность моделей. AutoResp не обходит эти ограничения.
